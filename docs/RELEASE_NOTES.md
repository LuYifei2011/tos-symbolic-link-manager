# 0.1.0 Beta

- 扫描指定目录或子目录中的符号链接，识别正常、失效、循环及无法检查的目标。
- 支持创建、修改目标、重命名和删除链接，提供搜索、状态筛选与目录选择器。
- 支持相对和绝对目标路径，可显式创建目标暂不存在的链接。
- TOS 会话与来源验证、当前用户共享目录检查、独立应用账号运行。
- 不覆盖同名文件；操作前验证链接指纹；扫描不进入链接目录。
- 集中工具栏与可排序链接列表；支持选中管理、完整路径详情和固定状态栏。
- 中英文与浅深主题设置；提供 amd64 和 arm64 安装包。
- 支持复选框多选、全选本页和批量删除确认；右键菜单提供修改目标、重命名、删除。
- 操作反馈使用 toast，应用链节图标去除四周透明留白。
- 针对启用时出现的 `216/GROUP`，在安装和升级的 postinst 中检查并补齐应用同名系统组；服务和 socket 保持专用用户、专用组配置。应用用户仍由 TOS 创建。

安装后需为 symlink-manager 应用账号配置所管理共享目录的文件权限，并只向可信任管理用户开放应用。Beta 需要在目标 NAS 固件上完成权限和生命周期验收。
