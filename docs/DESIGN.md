# 界面规范

模板沿用 TOS App Kit 和 batch-rename 的紧凑 TOS 工具窗口。用于已登录的 TOS 用户操作应用。

系统字体与 13px 基础字号适合桌面工具，蓝色用于主要动作和选择，浅深主题使用 App Kit 语义变量。单列内容按连接、操作、显示设置排列：先确认服务可用，再进行业务操作。宽屏内容上限 760px，避免简单表单横向拉长；窄屏表单改为上下排列。

顶部为公共 TosAppShell 的 41px 标题区域，右侧预留 180px 给 TOS 窗口控件。页面不绘制最小化、最大化和关闭按钮。控件圆角 4px，桌面至少 32px 高，620px 以下至少 44px 高。布局用间距和分隔线区分区域，不额外加入营销内容或装饰卡片。刷新和发送动作使用 Lucide 图标，随文字着色，线宽 1.6px。

默认内容是明确标注的请求示例，发送按钮为主要视觉焦点。加载、失败、断开和服务返回都有文字状态；诊断直接使用公共组件。原生表单保留键盘操作、可见焦点，状态使用 live region。用户输入用 Vue 文本插值显示。会话失效时前往 TOS 登录页，权限拒绝时仅显示访问提示；其他业务请求失败时保留页面供查看诊断。

`packaging/icon.svg` 是明确标注的占位图，前端 favicon 和 TOS 图标使用同一文件。下游发布前替换。
