# 界面规范

符号链接管理器以链接列表为主工作区。沿用 TOS App Kit 的标题栏、系统字体和浅深主题语义变量；标题只在窗口栏出现。主要使用 13px 正文、12px 工具栏与表头、11px 辅助路径和状态栏，蓝色用于主要操作与选中状态。

## 布局

应用填满窗口高度，依次为扫描地址栏、链接命令栏、可滚动列表和固定状态栏。960×600 的默认 TOS 窗口中，表头从约 143px 处开始，列表使用全部剩余高度。地址栏包含目录输入、目录选择、子目录选项和扫描按钮。命令栏包含新建、修改目标、重命名、删除、状态筛选、搜索与设置。

表格显示链接名称、相对扫描目录的位置、目标路径、状态和目标类型。名称与目标保持单行，长路径省略显示并提供完整 title。首列复选框支持多选，表头全选仅作用于本页；底部显示选中数量。单选时可修改目标、重命名和展开详细信息，多选时支持批量删除。点击行单选，Ctrl / Command 点击切换选择，筛选、排序、翻页与重新扫描会清空选择。列标题支持名称、目标和状态排序，翻页控件位于状态栏。

空状态保留表头。首次使用提供开始扫描，空目录提供新建链接，搜索无结果提供清除筛选。初次扫描时显示占位行，刷新时保留已有列表，操作状态和扫描统计位于底部。部分扫描结果和登录权限问题保留在工具栏下方；扫描完成、操作成功、取消及操作错误使用右上方 toast。成功提示 6 秒后消失，悬停或聚焦时暂停；错误提示保留至手动关闭。

## 窗口适配

720px 以下命令和筛选搜索分行，列表隐藏目标类型列；620px 以下扫描目录与子目录选项分行，触控按钮至少 44px。横向滚动限于表格区域，顶部命令和底部状态保持可见。桌面行高约 57px，内容不因长路径增高。

## 交互与主题

创建、修改、重命名、删除和设置使用带标题的原生 dialog。编辑时聚焦首要输入，保存期间禁止关闭。删除确认列出全部选中链接的位置与目标，并说明目标保留。批量删除逐条校验指纹，首次失败即停止，报告完成数量与失败位置；请求超时不自动重试。右键已选行保留多选，右键其他行改为单选；菜单提供修改目标、重命名和删除，支持 Shift+F10、上下键及 Escape。所有控件有键盘焦点、可访问名称，状态变化使用 live region。目录选择器继续使用 TOS App Kit。

正常状态使用绿色文字与圆点，失效和循环使用错误色，无法检查使用警示色；每个状态均保留文字。绿色浅色主题为 #23744c、深色为 #8bc6a1；警示色分别为 #8b6317 和 #dfbd7a，其余沿用 App Kit token。操作图标使用 Lucide，应用图标使用两段独立相扣的链节，前端资源离线可用。
